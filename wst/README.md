# wst

`wst` is the command-line interface for **Wan Shi Tong (WST)**.

`wst serve` runs the WST service. The other commands are clients of a running
service's JSON API (`/api/v1`, documented at `/api/docs`), meant for people and
for LLM agents working on a user's behalf; `--json` prints the API's responses.

Run `wst --help` for the complete usage documentation.
