# Wan Shi Tong — System Specification

This directory contains the **authoritative internal specification** for Wan Shi Tong (WST).

These documents define:
- What the system *is*
- What problems it is intended to solve
- The conceptual model and invariants
- The architectural boundaries between subsystems

They are **not user-facing documentation**.  
They are written primarily for:
- Contributors
- Future maintainers

## How to read this spec

- Start with `domain-model.md` as the semantic reference
- Use `architecture.md` to understand module boundaries
